# Anchor — Evidence-Based ADHD Digital Product Ecosystem Blueprint

A complete product-development blueprint for an evidence-based ecosystem of executive-function and financial-organization products for adults with ADHD — Etsy digital products, Notion templates, spreadsheets, printables, content, email, community, and a future SaaS app.

**The product is an executive-function prosthetic, not another planner.** It externalizes working memory, decisions, and time instead of asking users to try harder. Every design decision in this blueprint traces back to a canonical evidence base synthesized from four independent evidence reviews (2026-07-13), with explicit tiers separating what is clinically supported, moderately supported, experimental, and unsupported marketing.

> **Working name:** "Anchor" is a placeholder pending trademark/brand validation. It is used consistently so it can be search-replaced.

## The honest headline (so nobody skips it)

- Structured CBT/metacognitive **executive-function scaffolding works** in adults with ADHD (T1), including digitally delivered packages.
- **No tool — including ours — has ever been trial-tested head-to-head against a spreadsheet.** Superiority is a mechanism-based inference until we run the study (see Part 14).
- The **financial problem is proven; financial tools are not.** No savings/debt/bill-payment outcome claims until measured.
- **Abandonment is the bottleneck** (29% full-module completion in the best digital trials). Forgiveness and recovery ("Comeback Mode") are therefore first-class features, and engagement is a cost, not a goal.
